# PATCH_V144_212 — Grow Brain step 1: brand learning

## What changed
- Added a raw, server-only learning event log for customer post approvals and rejections.
- Added a compact per-brand learning profile that is rebuilt from the raw event history.
- Rejection reasons are weighted cautiously so an execution problem does not incorrectly ban an entire content type.
- Explicit recent rejection feedback is retained in the aggregate profile and can guide future copy generation.
- The AI Content Studio planner now receives mature-enough brand learning as a soft signal.
- The deterministic fallback planner and recurring weekly history-balanced selector use only small, confidence-gated preference adjustments.
- Existing approval/rejection flows remain fail-open if the new migration has not been applied yet; a learning-storage issue cannot block a customer's approval or rejection.
