# Spreelo v144.258 — International Stripe pricing

## Goal
Keep the Swedish Spreelo prices as the reference value while presenting clean, stable local prices to direct Stripe customers. Shopify App Store billing keeps its own public USD prices.

## Direct Stripe pricing
- SEK remains the default/base currency on the existing Stripe Price objects.
- Starter / Growth / Pro remain 299 / 599 / 999 SEK per month in Sweden.
- USD is fixed at $29 / $59 / $99 per month.
- EUR is fixed at €27 / €53 / €89 per month.
- 29 fixed currencies are included in the central price catalogue: SEK, USD, EUR, GBP, NOK, DKK, PLN, TRY, INR, IDR, JPY, KRW, CNY, THB, CZK, RON, HUF, MYR, PHP, CAD, AUD, BRL, MXN, CHF, AED, SAR, UAH, VND and RUB.
- Yearly direct prices are exactly 10 monthly prices, preserving the existing “2 months free” model.
- Extra credit packs use the same SEK-relative conversion principle and fixed local currency options.
- `STRIPE_LOCAL_PRICING_V144_258.csv` contains the reference FX conversion versus the chosen rounded price for every plan/currency.

## Customer-facing billing UI
- Removed hardcoded `kr` plan and credit-pack rendering from `StripeBillingPanel`.
- Direct customers see a local fixed currency based on this priority:
  1. existing Stripe subscription currency;
  2. Vercel request country (`x-vercel-ip-country`, with `cf-ipcountry` fallback);
  3. browser/app locale fallback.
- Shopify customers always see the public App Pricing amount in USD: $29 / $59 / $99 monthly and $290 / $590 / $990 yearly.
- Currency formatting uses `Intl.NumberFormat` with the selected Spreelo UI locale.
- Bulgaria maps to EUR because Bulgaria adopted the euro on 1 January 2026.

## Stripe Checkout
- Existing lookup keys and Price IDs are preserved.
- Checkout continues to use the existing multi-currency Price object by lookup key.
- Adaptive Pricing is enabled per Checkout Session by default as the fallback for a country/currency that does not have a fixed currency option.
- Set `STRIPE_ADAPTIVE_PRICING_ENABLED=false` only if Adaptive Pricing must be disabled temporarily.
- Manual `currency_options` override Adaptive Pricing for the fixed currencies.

## Stripe webhook accuracy
- Subscription state now stores `subscription.currency` as the authoritative charged currency.
- When Stripe provides the selected `currency_options` amount, Spreelo stores that local amount rather than the SEK default amount.

## One-time Stripe price sync
Added `scripts/sync-stripe-local-prices.mjs`.

Dry-run preview:

```bash
npm run stripe:prices:preview
```

Apply to a Stripe test/sandbox account after `STRIPE_SECRET_KEY` is present in the local environment:

```bash
npm run stripe:prices:sync
```

A live key is blocked unless the operator deliberately runs:

```bash
node scripts/sync-stripe-local-prices.mjs --apply --allow-live
```

The sync updates the existing Price objects with local `currency_options`; it does not create replacement products/prices or change lookup keys. It applies currencies independently so an account-specific unsupported currency is reported/skipped without blocking the other currencies.

## Preserved behavior
- Direct Stripe subscriptions, plan-change logic, credits and lifecycle remain in place.
- Shopify Partner API billing bridge from v144.257 remains unchanged.
- Shopify extra credit packs remain unavailable.
- No Supabase migration is required.
