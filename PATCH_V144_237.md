# Spreelo v144.237 — Shopify onboarding progress + i18n

## What changed
- Shopify App Store onboarding now uses Spreelo's persistent UI translation-key system.
- The verified Shopify installer locale is passed into the onboarding URL before the page renders, then stored through the normal Spreelo language state.
- All visible Shopify onboarding copy now comes from the `shopifyOnboarding` translation namespace.
- The Shopify brand-analysis screen now shows the same five analysis stages used by regular Spreelo onboarding.
- Analysis progress has a moving progress bar, connected stage dots, current-stage text, and percentage so merchants can see that work is continuing.
- Progress combines the server job progress with Spreelo's smooth visual progress behavior.
- Shopify analysis continues to use the same `/api/analyze-brand/start` and `/api/analyze-brand/status` flow and the same `/onboarding/ready` summary screen as regular onboarding.

## Database
No SQL migration is required.
