# PATCH_V144_211 — Planned-post mouse drag scrolling

## Changes
- Desktop users can now press and hold the left mouse button and drag the planned-post carousel horizontally.
- Pointer capture starts immediately so the drag keeps working even if the cursor leaves the carousel while held.
- Native browser image dragging is disabled for the carousel so it cannot steal the gesture.
- Cursor changes between `grab` and `grabbing`.
- Native touch/finger swiping remains unchanged on phones and tablets.
- Existing arrow-button and mouse-wheel navigation remains intact.
