# Spreelo v144.215 — Professional Grow Brain dashboard

## Goal
Turn Grow Brain steps 1–2 into a real customer-facing product experience instead of a backend-only learning system or a temporary TikTok review view.

## Added
- New permanent `/grow-brain` workspace page and sidebar navigation item.
- Professional responsive dashboard for every currently supported social channel:
  - Facebook
  - Instagram
  - TikTok
  - YouTube
  - Pinterest
  - Threads
- 7 / 30 / 90 day performance ranges.
- Per-channel filtering.
- Live KPI cards for measured posts, views, interactions, interaction rate, shares and clicks.
- Performance-by-publish-date chart using the normalized Grow Brain performance layer.
- Channel-level performance and analytics-health cards.
- Clear separation between publishing connection status and analytics permission/status.
- Top-content ranking from measured posts with direct links back to the Spreelo post.
- Customer preference-learning panel backed by `brand_learning_profiles` from Grow Brain step 1.
- Data-health / measurement-coverage panel.
- Explicit customer-facing note that step 2 is observational: performance data does not yet alter content planning automatically.
- Full responsive/mobile treatment.
- New English source labels in the normal Spreelo i18n system so other UI languages can use the existing translation-cache flow.

## TikTok permission hardening
TikTok `video.list` is now opt-in until TikTok approves the scope for the production app.

Default behavior:
- TikTok OAuth requests the existing publishing scopes only.
- TikTok can therefore remain usable for normal Spreelo publishing while `video.list` is under review.
- Grow Brain marks TikTok analytics as unavailable/pending instead of breaking the social connection.

After TikTok approves `video.list`:
1. Set `TIKTOK_ENABLE_PERFORMANCE_INSIGHTS=true` in Vercel.
2. Redeploy/restart the app so the environment value is active.
3. Reconnect TikTok once from Social channels.
4. The same Grow Brain page will start receiving TikTok performance data; no UI/code redesign is needed.

## Data behavior
- Reads `post_performance_latest` for normalized performance.
- Reads `post_performance_collection_state` for analytics health/scope diagnostics.
- Reads `brand_learning_profiles` for approval/rejection preference learning.
- Reads matching Spreelo posts for customer-friendly top-content labels and direct post links.
- No step-3 strategy mutation has been enabled in this release.

## Database
No new SQL migration is required for v144.215. It uses the v144.212 and v144.213 Grow Brain tables already deployed.
