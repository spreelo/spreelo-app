# Spreelo v144.271 — Growth Agent V2 admin rollout + shadow mode

- Admin per customer: Off / Shadow / Active.
- No new Vercel environment variable is required.
- Shadow keeps the existing planner in control and stores a separate deterministic Growth Agent candidate using the same history, Grow Brain and customer-learning inputs. It adds no extra OpenAI call.
- Active enables the V1 planning influence for that customer.
- Existing active calendar items are not rewritten by this route.
- Rescue, Shopify import, brand analysis and content generation are not changed.

Required: run `supabase/v144_271_growth_agent_v2_admin_shadow.sql` once before using the controls.
