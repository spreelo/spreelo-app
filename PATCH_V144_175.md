# Spreelo v144.175 — Focused Carousel Verified Reserve Pool

Base: **v144.174**

## Purpose
Fix the ordinary focused/category carousel failure where previously used verified products were excluded during discovery before the later reuse selector could ever see them.

Observed Köttfabriken failure:
- focused source: `/c/farskvaror`
- 28 previously used/known product URLs excluded during Store Map shelf discovery
- remaining candidates were mostly category/listing pages
- verification ended with 0 usable products
- terminal `carousel_product_prepare / no_suitable_product`

## Changes

### 1. Source-safe verified reserve pool for ordinary focused carousels
For non-campaign `product_category` / `focus_page` carousels, Spreelo now loads the brand-wide active verified catalog before discovery and recovers only products proven to belong to the focused source by either:
- exact/descendant persisted `source_url`, `store_map_node_url`, or `category_urls`, or
- exact product URL/title/image match against prior content history from the same focused source.

Unrelated brand-wide products are not allowed into the focused category pool.

If this source-proven verified pool already contains five eligible products, the existing verified-catalog early exit can complete the carousel before live category crawling.

### 2. Store Map no longer pre-excludes used products for ordinary 5-product carousels
For ordinary non-campaign carousels requiring five products, Store Map now leaves previously used product URLs eligible during discovery.

This is necessary because product reuse is an accepted last-resort completion path. Previously those products were removed before verification, so `allowReuseWhenExhausted: true` later in the selector could never recover them.

Fresh products still rank before reused products in `selectCarouselProductsFromPool()`.

Calendar campaigns retain the previous used-product exclusion and campaign-aware reuse ladder, so campaign relevance/theme protection is unchanged.

### 3. Focused discovery combines new + safe verified reserve products
If fewer than five verified products are available before discovery, newly discovered focused products are combined with the safe source-proven verified pool. Selection remains:
1. unused/fresh products first
2. least-used / oldest-used verified products to fill missing positions
