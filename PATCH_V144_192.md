# Spreelo v144.192 — onboarding readability + mobile fit

Refinement of the approved v144.191 onboarding layout. No business logic or database changes.

## Updated
- Larger, more readable typography throughout desktop and mobile onboarding.
- Stronger section/card headings and supporting text.
- Brand name in the intro is bold and highlighted with Spreelo orange (`#f06445`).
- Planned post type names now use colored highlight pills for faster scanning.
- Larger planned-post dates/labels and larger social channel icons.
- Primary `Aktivera planen` CTA is substantially taller and more touch friendly, with enforced white icon/text.
- Mobile onboarding starts below the dark app header + beige brand strip instead of overlapping them.
- Mobile modal is horizontally centered with nearly edge-to-edge width and equal small side margins.
- Existing v144.191 layout, channel add button, editable preview images, plan data and one-time behavior remain unchanged.
