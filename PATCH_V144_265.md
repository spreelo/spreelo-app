# Spreelo v144.265 — Social OAuth diagnostics + popup rollback

This is a stabilization/diagnostic patch, not a redesign.

## Changes

- Restores `app/social-channels/page.jsx` to the v144.263/v144.262 popup behavior by basing this package on v144.263. The v144.264 popup reconciliation experiment is not included.
- Keeps the v144.263 credit-balance self-heal and the v144.262 billing/currency changes.
- Adds stage-based server diagnostics to the shared Free-trial/credit path:
  - balance ensure start/existing/create/error
  - social trial preflight start/balance-ready/allowed
  - social trial authorization start/balance-ready/claim result/error
- Adds explicit Facebook page-selection stages so Vercel logs identify whether a failure happened during:
  - authentication/session loading
  - trial preflight
  - connection save
  - trial authorization
  - cleanup/completion
- Diagnostic IDs are shortened in the shared trial logger. Tokens, OAuth codes and access tokens are not logged.

## Test procedure

1. Deploy v144.265. No new SQL is required beyond the v144.263 migration already applied.
2. Test Facebook only once from Social channels.
3. If it fails, copy the Vercel log lines beginning with `[meta-page-selection]` and `[social-trial]`, plus the final `Meta page selection POST error` line.
4. Do not make additional OAuth/UI changes until that log identifies the failing stage.
