# v144.279 — Shopify disconnect & billing deletion hardening

## Goal
Close the remaining Shopify lifecycle gaps before end-to-end App Store testing without changing content planning, campaign calendars, Growth Agent, Automation, or normal non-Shopify customer behavior.

## Changes
- Account deletion is now billing-provider aware:
  - Stripe subscriptions are cancelled only through Stripe.
  - Shopify App Pricing subscriptions are cancelled through Partner API `appSubscriptionCancel`.
  - Shopify cancellation first verifies the active subscription via Partner API and fails closed if cancellation cannot be verified.
- Manual Shopify disconnect now:
  - revokes stored Shopify tokens and marks the connection disconnected instead of deleting its identity,
  - marks Shopify catalog rows inactive,
  - disconnects only the Shopify web-data state,
  - disables product mode only when that capability was derived from Shopify Admin API,
  - preserves separately verified ordinary website product-mode data.
- Account deletion UI copy is provider-neutral rather than Stripe-specific.
- Partner API setup docs now include both `Manage apps` and `View financials`; Shopify requires the latter for `appSubscriptionCancel` in API 2026-07.
- v144.247/v144.248 regression parsers were made resilient to additional exported Shopify query/helpers introduced by later versions.

## No SQL
No database migration is required.
