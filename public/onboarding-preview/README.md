# Onboarding preview images

These five images are used only in the first-time AI Content Studio onboarding popup.

To change the example images later, replace these files with new PNG images using the same filenames:

- `post-1.png`
- `post-2.png`
- `post-3.png`
- `post-4.png`
- `post-5.png`

No database change is required when replacing them.
The layout uses `object-fit: cover`, so landscape crops work best.
