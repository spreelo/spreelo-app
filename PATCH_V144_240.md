# v144.240 — Shopify entry parity

Shopify is now treated only as an alternative acquisition/authentication bridge. After the verified merchant is inside Spreelo, the same account lifecycle used by ordinary Spreelo sign-up applies.

- Ensures a Shopify-created Spreelo user has the normal Free account credit state if it was missing: 100 promotional credits reserved/locked until an eligible social channel is connected, exactly like ordinary sign-up.
- Requests the same deduplicated welcome lifecycle email for first-brand Shopify users.
- Carries the claimed Shopify brand id explicitly through Grow Brain, analysis summary and Social Channels so a multi-brand account cannot silently fall back to another brand.
- Social Channels and Grow Brain validate an explicit `brandId` against the authenticated user before selecting it.
- Keeps v144.239 analysis-integrity behavior: analysis must really complete before the standard `/onboarding/ready` summary is shown.
- Keeps the same normal analysis engine, translation system, summary page, social onboarding, plan limits and free-trial activation rules.

No SQL migration is required.
