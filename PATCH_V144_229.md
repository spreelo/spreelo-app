# Spreelo v144.229 — Grow Brain Step 4 + readability polish

## Step 4: performance learning now influences future planning
- New plans load `brand_performance_insights` together with the current performance-learning state.
- Established performance signals softly adjust content-type selection.
- Goal-aware evidence weighting:
  - Sell more emphasizes click/save evidence.
  - Get more followers emphasizes exposure/engagement/share evidence.
  - Build trust emphasizes save/share/engagement evidence.
- Same-channel normalization from Step 3A remains the basis; raw TikTok reach is never directly compared with Facebook reach.
- Influence is capped and requires at least 4 observations plus confidence >= 0.35.
- `collecting` performance learning has zero planning influence; `early` is deliberately reduced; `established` gets full capped influence.
- Negative signals are weakened further so Grow Brain reduces repetition rather than hard-banning a content type.
- AI plan creation receives a compact Grow Brain performance context.
- Recurring adaptive weekly plans also use the same performance adjustment deterministically when choosing the next variant.
- Existing older weekly plans remain compatible; they can still use brand-wide signals even when they predate stored platform selection in adaptive config.

## UI polish
- Step 3B heading/body/card text now matches the established Grow Brain readability hierarchy.
- The old “Step 4 disabled” note is replaced by an explanation that learning now nudges planning conservatively.
- Top Content cards now have enough height for their metric footer.
- Metric labels can wrap instead of being clipped.
- All Top Content cards use the same 1px thin border/separator treatment.

## Database
No new SQL migration is required. Step 4 reads the Step 3A tables introduced in v144.225.
