# Spreelo v144.235 — Shopify first-time analysis result

- Shopify App Store first-time onboarding now runs the same `/api/analyze-brand/start` analysis used by regular Spreelo onboarding.
- The Shopify onboarding waits for the analysis job to finish using the same durable status endpoint and session refresh helper.
- After a successful first analysis, the customer is sent to the existing `/onboarding/ready` analysis result experience instead of directly to Social channels.
- The existing result screen remains unchanged and its primary CTA continues to Social channels.
- Existing Spreelo customers that only add Shopify keep the existing Grow Brain return path.
- If the customer declines store-data AI consent, Spreelo can still run the normal public website brand analysis; the declined consent only blocks Shopify store-data personalization.
- No database migration is required.
