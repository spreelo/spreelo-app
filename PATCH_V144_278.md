# v144.278 — Shopify brand analysis Admin API context

## Goal
Make Shopify brand analysis resilient when the storefront is password-protected or otherwise unreadable, without changing the existing campaign calendar, Automation, Growth Agent, or non-Shopify analysis behavior.

## Changes
- Added a Shopify Admin API brand-analysis context query using the existing `read_products` permission.
- Brand analysis now enriches normal website evidence with verified Shopify shop/product data (product titles, descriptions, vendor, product type, and tags).
- Shopify product candidates are merged ahead of website-derived candidates so the analysis always has structured assortment evidence.
- If the storefront homepage/context pages are blocked but Shopify API context is available, analysis continues from verified Shopify data instead of producing an empty/unknown profile or requiring website rescue.
- For non-Shopify brands, website fetch/security behavior is unchanged.
- Existing campaign calendar and campaign-opportunity generation remain untouched; they receive the improved brand-analysis result through the same pipeline as before.

## No SQL
No database migration is required.
