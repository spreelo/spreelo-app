# Spreelo v144.268 — Preserve social connection when free trial is unavailable

## Root cause
`claim_spreelo_social_trial(...)` correctly detected reused trial identities, but its denial branches also changed the newly saved `social_connections` row to `disconnected` and cleared provider tokens. That made a valid Facebook/Instagram/etc. connection appear successful and then immediately disappear.

## Fix
- Free-trial denial remains intact (`allowed: false` with the existing reason code).
- The trial RPC no longer changes `social_connections` status or clears OAuth tokens when a trial is denied.
- This applies to reused social account, already-used Spreelo account, reused business/domain, and unique-claim race cases.
- v144.267's user-facing notice remains in place, so the user can be told that the channel connected but no new 100-credit trial was granted.
- No OAuth, popup, provider callback, paid-plan, or credit-award behavior was otherwise changed.

## Database
Run `supabase/v144_268_social_trial_preserve_connection.sql` in Supabase before/with the deployment.

## Expected result
A previously trial-consumed Facebook page can connect successfully. The connection stays `connected`; the user receives no duplicate free credits and sees the existing trial notice.
