# Spreelo v144.253 — Shopify automation recovery + explicit activation limits

This patch addresses two issues found in the first live Shopify automation test on 2026-09-23.

## 1. Shopify Product Engine recovery
- Keeps the Shopify Admin API catalog as the authoritative primary product source.
- Skips Store Map crawling when a valid Shopify primary catalog is already available.
- Removes AI Product Ad image-boilerplate phrases from product-intent extraction so phrases such as "include short readable marketing text" cannot become product-search queries.
- If every campaign-fit Shopify product has been used recently, the engine may start a new rotation cycle and reuse the best verified campaign-fit Shopify product instead of abandoning the API catalog and crawling a password-protected storefront.
- Reuse remains campaign-fit gated and Shopify-verified; unrelated products are not forced into a post.
- Existing public-web research remains available when Shopify genuinely cannot satisfy the requested product intent.

## 2. Activation-limit UX
- Credit shortage no longer silently disables the activation button.
- The customer can press Activate and receives the existing explicit credit-limit message with required/remaining credits.
- Existing plan-limit database handling remains unchanged and continues to open PlanLimitModal with the current plan, limit and upgrade path.

No SQL migration is required.
