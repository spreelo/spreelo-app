# Spreelo v144.232 — Shopify V1 OAuth + product catalog connector

## What is implemented
- Real Shopify OAuth authorization-code flow for standalone Spreelo.
- Signed short-lived state + HttpOnly SameSite=Lax cookie for CSRF protection.
- Shopify callback HMAC verification and strict `.myshopify.com` validation.
- Expiring offline access tokens (`expiring=1`) with rotating refresh-token support.
- Server-only `shopify_connections` table; browser users receive no grants to token rows.
- `read_products` catalog endpoint via Shopify GraphQL Admin API 2026-07.
- Grow Brain's existing web-data discovery now extracts the store's `.myshopify.com` domain when exposed by the storefront.
- Shopify recommendation in Grow Brain now launches the actual authorization flow instead of only marking `setup_pending`.
- Connected state and disconnect action in Grow Brain.

## Required environment variables
Already expected in Vercel Production:
- `SHOPIFY_CLIENT_ID`
- `SHOPIFY_CLIENT_SECRET`
- `SHOPIFY_API_VERSION=2026-07`
- `SHOPIFY_SCOPES=read_products`
- `SHOPIFY_REDIRECT_URI=https://app.spreelo.com/api/shopify/callback`

## Deploy order
1. Run `spreelo-v144.232-SQL.sql` in Supabase.
2. Deploy this code to Vercel.
3. Test with a Shopify development store.

## Current scope
This version deliberately reads products only. It does not request orders/customers or protected customer data yet.
App Store compliance webhooks and Shopify Billing are launch-stage tasks and are not needed for the first development-store OAuth test.
