# Deploy v144.226

1. Deploy the zip normally. No SQL migration is needed if v144.225 SQL has already been run.
2. Sign in with a Spreelo administrator account.
3. Open `/grow-brain?demo=1`.
4. In the Step 3A verification panel, click **Run engine test**.
5. A successful run should report 36 eligible posts, stored insights, and both positive and negative sample signals.
6. After inspection, click **Clear test data**.

The test data is isolated under a synthetic brand ID and does not belong to the currently selected real brand.
