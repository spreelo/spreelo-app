# Spreelo v144.254 — Shopify Embedded App + App Bridge authentication

## Goal
Open Spreelo directly inside Shopify Admin without replacing Spreelo's existing Supabase authentication or changing the normal customer experience.

## Changes
- Loads Shopify's current CDN-hosted App Bridge script and Shopify client ID meta tag.
- Keeps App Bridge automatic `fetch` and `auto-redirect` features disabled so existing Spreelo `Authorization: Bearer <supabase token>` calls are not overwritten.
- Adds `/shopify/app` as the embedded App Home entry.
- `/shopify/app` obtains a fresh Shopify ID token with `shopify.idToken()` and sends it only to Spreelo's backend.
- Adds server-side HS256 Shopify ID-token validation (`exp`, `nbf`, `aud`, `iss`/`dest`, signature).
- Uses Shopify token exchange for:
  - online token: current Shopify staff identity/email,
  - expiring offline token + refresh token: Spreelo background product/catalog/automation work.
- Existing linked store: creates a seamless Supabase session only when the current verified Shopify email matches the linked Spreelo account owner.
- New store: creates the existing short-lived Shopify onboarding handoff and reuses the current brand-selection/consent/analysis onboarding.
- Embedded onboarding no longer depends on third-party cookies; it can pass the onboarding session ID in the authenticated request body.
- Existing OAuth flow under `/api/shopify/connect` remains intact for Shopify connections initiated from Spreelo/Grow Brain.

## Safety boundary
This patch does **not** change normal Spreelo generation, Product Engine strategy, Grow Brain, credits, plans, social publishing, or non-Shopify authentication.

## SQL
No SQL migration is required.
