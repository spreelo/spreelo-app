# Spreelo v144.285 — Shopify authoritative product selection

## Problem
Connected Shopify stores already expose verified active products and exact product images through the Shopify Admin API, but product/video automation could still reject those products using the generic website text-fit threshold and fall through to storefront/web research. Password-protected Shopify storefronts then failed with `no_suitable_product` and could require Admin Rescue even though valid Shopify products were already available.

## Fix
- Shopify Admin API products are now authoritative for connected Shopify stores.
- A Shopify product may proceed when it is identity locked, promotable/active and not explicitly rejected for the campaign.
- The soft generic website text-fit score remains useful for ranking, but can no longer veto a valid Shopify product.
- Ranked Shopify products are prepared before storefront fallbacks, including password-protected stores.
- Rotation reuse uses the same authoritative Shopify eligibility rule.
- Web research remains available only when the Shopify catalog genuinely cannot provide a valid product.

No SQL required.
