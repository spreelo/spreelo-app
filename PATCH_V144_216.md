# Spreelo v144.216 — Grow Brain premium redesign

## What changed

This release redesigns the real Grow Brain dashboard to match the premium design direction approved from the visual concept, while preserving real production data and the existing Grow Brain step 1/2 logic.

### Visual redesign
- New premium Grow Brain hero with a branded neural/performance visual, connected social-channel icons and stronger visual hierarchy.
- Refined intelligence-status card and live-update treatment.
- Dedicated Key metrics heading and upgraded KPI cards.
- Performance graph now combines post-volume bars with the selected performance trend and visible data points.
- Customer-learning panel now shows learning maturity as a percentage, keeps the conservative 12-decision threshold and uses Spreelo-purple progress styling.
- Learning signal names now resolve through Spreelo's translated content-type labels instead of exposing raw internal identifiers where a translation exists.
- Channel performance cards have clearer status, hierarchy and spacing.
- Coverage copy now distinguishes "connected but waiting for data" from an actual measurement failure.
- Top content has been redesigned from a technical row list into visual content cards using the real post image when available.
- Data-quality card and mobile layout have been visually refined.

### Data behaviour
- No changes to Grow Brain's collection or strategy logic.
- No fake growth percentages or demo metrics have been introduced.
- All displayed metrics still come from the existing production performance tables.
- No database migration is required.
