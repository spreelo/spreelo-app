# Spreelo v144.196 — Home parity + planned-post preview redesign

- Rebuilt the three summary categories around one shared DOM/layout contract.
- Changed the three outer wrappers from legacy `article` elements to isolated `section.home-plan-section-v196` wrappers so old article-specific CSS can no longer push Planned posts and Calendar campaigns into a different alignment.
- Recurring schedules, Planned posts and Calendar campaigns now use the same icon / title / status / description / CTA layout. Only accent color and content differ.

## Workspace loader
