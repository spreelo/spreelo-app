# Spreelo v144.276 — Growth Agent V7 Closed Loop

V7 closes the planning/learning loop without replacing existing Spreelo engines.

## What it does
- Records each Growth Agent planning decision in Shadow or Active mode.
- Stores the Growth Profile / commerce evidence snapshot that existed when the decision was made.
- On a later planning run, compares open cycles against newly observed Grow Brain / commerce evidence.
- Marks a cycle as `feedback_observed` only after enough genuinely new evidence appears.
- Exposes the latest closed-loop cycles in Admin per customer.

## Safety rules
- No existing/approved/active calendar item is rewritten.
- Feedback only influences future planning through the existing Growth Profile / Growth Agent pipeline.
- Later performance is explicitly treated as feedback, not proof that the Growth Agent caused the result.
- Shadow mode remains non-influencing for the real plan.
- No extra OpenAI call is introduced by V7.

## Migration
Run `supabase/v144_276_growth_agent_v7_closed_loop.sql` after the V2–V6 migrations.
