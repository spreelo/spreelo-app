# Spreelo v144.227 — Grow Brain Step 3B performance insights

## What changed
- Added a customer-facing performance-learning section to Grow Brain.
- Reads the real `brand_performance_insights` and `brand_performance_learning_state` rows created by Step 3A.
- Separates positive audience-performance signals from patterns that need improvement.
- Shows channel/context, observations, confidence, performance score, and the strongest relative evidence (engagement/exposure/click/share/save).
- Honors the Grow Brain channel filter for channel-specific insights.
- In `?demo=1`, the dashboard can load the persisted isolated Step 3A engine-test results so the UI shows the actual verified test insights instead of invented 3B values.
- Step 3B remains observational only. No performance insight is wired into planning or content generation yet.

## Database
No new SQL is required. This version uses the Step 3A tables created by `spreelo-v144.225-SQL.sql`.
