# Spreelo v144.160 — explicit plan language + manual prompt language + product-title safety

This patch is intentionally scoped on top of v144.159.

## Changes

- AI Content Studio and campaign planners no longer expose an `Automatic` content-language option.
- The analyzed/current brand content language is shown directly as the selected language. All 30 official Spreelo languages remain available for an explicit override.
- `Custom post` / `manual_prompt` keeps prompt-language detection as an internal mode only when the user has not explicitly changed the language. An explicit language selection always wins.
- Downstream carousel text generation uses the same rule-aware language instruction as the main post, so a custom prompt stays in its prompt language across supported formats.
- Generic product image metadata such as `Product image`, `Product photo`, `Image`, `Produktbild` and equivalents can no longer be accepted as a customer-facing product title.
- Product-title recovery tries verified structured product name, product-page H1, page metadata/research title and finally the exact product URL slug as a bounded fallback.
- Product image typography has a final fail-closed guard: when no verified public product title is available, the image contains the headline only rather than inventing or displaying a placeholder product-name row.
- Public product overlay/card/email title paths reject generic placeholder titles as an additional defense for older stored data.
- Social Channels functionality is intentionally untouched from v144.159.

## Database

No SQL migration is required for v144.160.
