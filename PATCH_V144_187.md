# Spreelo v144.187 — Onboarding reference-match correction

This release is a presentation-only correction on top of the direct v144.183 → v144.186 work. It does **not** use the discarded Codex v144.184/v144.185 branch.

## What changed

- Rebuilt the smart first-plan modal to follow the approved desktop/mobile reference instead of the long accordion-like layout.
- Desktop now uses one compact **Your recommended plan** card with a 2-column overview.
- Mobile uses the same visual language but collapses to six concise rows, matching the supplied phone reference.
- Removed the separate Why / Plan settings / Content types panels from the modal.
- Removed the visible Skip link; the close button still dismisses the recommendation.
- Removed the modal's normal internal scroll area. Ordinary desktop and modern phone heights fit without scrolling; very short phone/landscape viewports retain a safe scroll fallback to avoid clipping.
- Uses the current brand logo in the small visual tile when available; otherwise the existing Spreelo AI visual remains.
- Keeps the real plan goal, frequency, publishing days, channels, estimated credits and selected content mix connected to the existing v144.186 logic.
- New copy uses fresh English canonical i18n keys so existing cached translations are not confused with the old modal wording.

## Unchanged

- v144.182 smart content strategy.
- v144.183 recurring-plan credit pause/resume.
- v144.186 smart recommendation logic.
- v144.186 admin team invitations/security.
- Plan entitlements and admin bypass.
- Social integrations, publishing, rescue and campaign logic.
