# Deploy Spreelo v144.187

## Database

No new SQL is required for this version.

Prerequisite: the normal v144.186 SQL migration should already be applied to the existing v144.183 database.

## Deploy

1. Do not run any additional SQL for v144.187.
2. Deploy the v144.187 application package.
3. Open AI Content Studio as the internal tester and verify the first-plan modal on desktop and mobile.
4. Confirm that the modal shows without scrolling on a normal desktop viewport and a normal portrait phone viewport.
5. Confirm that Activate plan and Review and customize still perform their existing actions.
