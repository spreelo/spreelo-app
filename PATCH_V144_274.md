# Spreelo v144.274 — Growth Agent V5 Opportunity Detection

Builds on v144.273 without replacing Shopify, rescue, brand analysis, Grow Brain or the existing content engine.

## Added
- Detects recently discovered verified products that have not yet been used.
- Detects verified products that have never been used in social content.
- Detects products not used for roughly 45 days.
- Detects relevant campaign windows within roughly 30 days.
- Reuses Growth Profile to surface safe underexplored formats.
- Stores active opportunities per brand for admin review.
- Resolves opportunities automatically when the underlying signal disappears.
- Feeds opportunities into Growth Agent as soft planning signals only.

## Safety
- Shadow mode still never changes the real plan.
- Active mode only influences future planning decisions.
- Existing active calendars are never rewritten.
- Product opportunities come only from Spreelo's verified existing catalog; Growth Agent does not invent catalog items.
- No additional AI call was added.
