# Spreelo v144.163 — UI/i18n label cleanup

## Scope

Two targeted UI/i18n fixes on top of v144.162. No product-research, publishing, Social Channels, billing or database schema changes.

## Changes

- Treats `Kling · AI video` as an intentional language-neutral system label. Language-neutral labels are seeded directly from the English source pack and skipped by the AI translator, preventing repeated `likely_english` warnings and unnecessary translation calls.
- Planned content on Home now resolves known content types from stable `content_type_id` values before falling back to legacy stored `content_type_label` text.
- New automation rules persist canonical English content-type labels (for example `Product post`) instead of persisting a localized UI translation. UI localization remains presentation-only through i18n.
- Existing rules that contain an old malformed translated label such as `ProduktinläGg` are therefore displayed through the canonical content-type translation instead of the stale stored label.

## Database

No SQL migration is required. Existing rows are not rewritten; the UI safely ignores stale localized labels for known content type IDs, while future saves use English canonical labels.
