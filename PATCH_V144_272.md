# Spreelo v144.272 — Growth Agent V3 Growth Profile

V3 builds on v144.271 and does not replace the existing Spreelo engines.

## What is new
- Durable Growth Profile per brand in `growth_agent_profiles`.
- The profile is derived from existing Grow Brain performance evidence and existing customer-learning signals; no additional OpenAI request is required.
- Conservative learning states: `collecting`, `early`, `established`.
- Data quality: `limited`, `developing`, `strong`.
- Learned strengths/weaknesses only influence planning when there is enough real evidence.
- Profile influence is capped to a small second-order nudge; it cannot hard-ban a format or bypass goal/channel/capability safeguards.
- Shadow mode uses the Growth Profile in its candidate while the existing planner remains in control.
- Active mode uses the same profile for new planning decisions only.
- Existing active calendar items are not rewritten.
- Admin customer view shows profile state, evidence volume and learned strengths.

## Unchanged
- Rescue
- Shopify import/catalog
- Brand analysis
- Content generation
- Existing scheduled/active calendar items
- Vercel environment variables (none are required for normal admin-controlled operation)

## Required
Run `supabase/v144_272_growth_agent_v3_growth_profile.sql` once after the v144.271 SQL.
