# v144.246 — Shopify product-mode activation

- Fixes Shopify-connected stores being hidden from Product Post / Product Ad / Product Carousel formats when the older public-website analysis did not set `website_product_mode_available`.
- Spreelo now verifies the connected Shopify Admin API catalog with the exact same strict Product Engine rules used for generation: ACTIVE product, Online Store URL, available-for-sale variant and a verified product image.
- One eligible Shopify product is enough to activate product mode.
- A positive Shopify verification is persisted to the existing brand product-mode fields so all established Spreelo planning/generation flows agree that the store has products.
- A failed Shopify probe never overwrites an already-valid website-analysis product mode and never invents product availability.
- AI Content Studio checks this automatically before hiding product formats.
- Weekly AI planning, campaign planning and smart onboarding also resolve Shopify-backed product mode server-side for consistency.
- No database migration is required.
