# Spreelo v144.228 — Grow Brain Step 3B runtime fix

Fixes a client-side crash introduced in v144.227 when performance insight cards are rendered.

## Root cause
`PerformanceInsightCard` called `clamp(...)` to normalize confidence values, but no `clamp` helper existed in `app/grow-brain/page.jsx`.

## Fix
Adds a small numeric `clamp(value, min, max)` helper next to `safeNumber`.

No SQL or environment changes are required.
