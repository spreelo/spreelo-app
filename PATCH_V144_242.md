# Spreelo v144.242 — Shopify hardening + sidebar readability

## Shopify
- Manual Grow Brain Shopify OAuth now returns to the exact originating brand via explicit `brandId`.
- Added a short-lived database-backed refresh lock for expiring Shopify offline tokens.
- Concurrent serverless requests now wait for the winning refresh instead of rotating the same refresh token in parallel.
- Shopify GraphQL calls now retry once after a real HTTP 401 by forcing a safe token refresh.
- A second 401 after refresh marks the connection `reconnect_required`.
- Product reads use the hardened per-brand GraphQL helper.
- Legacy v144.234–v144.236 regression checks were updated to reflect the current shared analysis-summary onboarding flow.

## Sidebar readability
- Plan label: 13.5px.
- Included-credit text (`/ 450 credits left`): 13.5px.
- Credit reset line: 13.5px.
- Account label: 13.5px.
- Email: 13.5px when it fits, with a bounded automatic reduction for longer addresses and ellipsis as a final safety fallback.

Run `spreelo-v144.242-SQL.sql` before deploy. It adds only two nullable server-only refresh-lock columns plus an index.
