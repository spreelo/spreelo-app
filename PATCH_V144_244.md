# v144.244 — Free social entitlement + Facebook plan-limit handling

## Fixes
- Restores **1 connected social account on Free**, required by the existing cardless 100-credit trial flow.
- Preserves paid capacities: Starter 1, Growth 5, Pro unlimited.
- Converts database `SPREELO_PLAN_LIMIT` failures in Facebook page selection from an opaque HTTP 500 into a structured HTTP 409 response.
- Shows a translated, customer-facing plan-limit message instead of `Could not save selected Facebook page`.

## Root cause
`v144.180` intentionally set Free social accounts to 1. A later `v144.186` replacement of `spreelo_entitlement_limit()` accidentally set the Free fallback to 0, while the application entitlement model still expected `socialAccounts: 1`.

## Deploy
1. Run `spreelo-v144.244-SQL.sql` in Supabase.
2. Deploy the v144.244 application package.
3. Retry the Facebook connection on the Free Shopify test account. No reinstall of Shopify is required.
