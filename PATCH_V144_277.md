# Spreelo v144.277 — Growth Agent V7 closed-loop idempotency

Adds idempotency/deduplication before Growth Agent shadow/active rollout.

## What changed
- Each plan-content request now carries a planning event id.
- Equivalent rapid duplicate UI requests reuse the same event id for a short 3-second guard window.
- Closed-loop audit cycles store a deterministic `cycle_key`.
- A unique database index prevents concurrent/retried writes from creating duplicate cycles.
- PostgreSQL unique-conflict (`23505`) is treated as idempotent success and the existing cycle is returned.
- Older/non-UI callers still get a safe server-side 10-minute fallback dedupe window.

## Safety
- No existing calendar, automation rule, Shopify import, rescue flow, or content generation path is rewritten.
- The change only affects Growth Agent V7 audit-cycle persistence.

## Migration
Run `supabase/v144_277_growth_agent_v7_closed_loop_idempotency.sql` after the v144.276 migration.
