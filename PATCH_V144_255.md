# Spreelo v144.255 — Shopify shop-to-brand isolation

## Purpose
Prevent a Shopify App Store / embedded install from opening or claiming a Spreelo brand that belongs to a different Shopify store owned by the same Spreelo account.

## What changed
- Added exact `.myshopify.com` identity matching in `lib/shopifyBrandIsolation.js`.
- Embedded App Bridge bootstrap now validates the stored `shopify_connections.brand_profile_id` before auto-login.
- A stale connection is no longer trusted just because the same Spreelo user owns the brand.
- If another brand on the same account is an exact match, the shop connection is repaired to that brand automatically.
- If no exact brand exists, Shopify onboarding creates a dedicated brand for the current `shop_domain`.
- New App Store-created brands are anchored to `https://<shop>.myshopify.com` for durable identity.
- Old App Store-derived web-data signals cannot self-prove a stale mapping when the brand URL points at another Shopify shop.
- When a stale App Store mapping is rebound, the old brand's derived `brand_web_data_connections` row for that shop is removed so Grow Brain cannot keep showing the wrong store as connected.
- If legacy data contains multiple exact duplicate brands, Spreelo refuses to guess and only allows choosing among those exact matches. It does not offer creating yet another duplicate.

## Isolation boundary
The normal Grow Brain/manual Shopify connector remains unchanged. This patch only tightens App Store / embedded shop-to-brand identity handling.

## Database
No SQL migration is required.
