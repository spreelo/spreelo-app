# v144.284 — Shopify Authoritative Rotation Fix

## What changed
- Shopify Admin API catalog remains authoritative for product-based posts even when the storefront is password-protected.
- When campaign-fit Shopify products are exhausted by recent-use rotation, Spreelo may reuse the least-recently-used suitable verified Shopify product instead of falling through to storefront/web research.
- Campaign-fit and Shopify Admin API identity locks remain required.
- Generic web fallback remains available only when the authoritative Shopify catalog truly cannot satisfy the task.

## Database
No SQL changes required.
