# Spreelo v144.159 — language, login progress and logo polish

Built on v144.158. No database migration is required.

## Changes

- One canonical 30-language catalogue now drives both app-language and content-language choices.
- AI Content Studio exposes all 30 official languages plus an explicit `Automatic (brand default)` fallback.
- Brand Profile exposes the same 30 post languages.
- Settings > Language now lets the user save the current brand's default post language.
- New AI plans inherit that brand language automatically; campaign handoffs fall back to it when the campaign has no explicit language.
- Manual post creation also uses the same 30-language catalogue.
- Login send-code, resend and verify actions show a rotating progress icon while requests are running.
- Brand logo preview is slightly larger and matches the larger real generated-image overlay.
- `Change logo` and `Remove logo` use the same 44 px button height.
- Social Channels remains on the v144.158 restored implementation; no social OAuth/publishing logic is changed in this patch.

## Deployment

Deploy the application normally. There is no v144.159 SQL migration.
