# Deploy Spreelo v144.231

1. Run `spreelo-v144.231-SQL.sql` in Supabase SQL Editor.
2. Deploy the application ZIP.
3. Open Grow Brain for a brand without a website-data connection.
4. Verify the one-time optional prompt.
5. Choose `Not now`, reload, and confirm the prompt does not return automatically.
6. Use the permanent `Connect website` button and verify website stack discovery/recommendation.

No external provider credentials are added by this patch. Shopify/WooCommerce/Google provider authorization remains the next implementation step.
