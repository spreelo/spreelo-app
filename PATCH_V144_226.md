# Spreelo v144.226 — Grow Brain Step 3A isolated engine test

## Purpose
Adds a safe admin-only verification harness for Grow Brain Step 3A while Spreelo has no live customers/performance rows yet.

## What it does
- Adds an admin-only endpoint: `/api/admin/grow-brain-performance-test`.
- Generates 36 synthetic performance rows across Facebook and Instagram.
- Uses a separate deterministic test brand ID per administrator.
- Sends the rows through the real `post_performance_latest` -> `rebuildBrandPerformanceInsights` -> `brand_performance_insights` / `brand_performance_learning_state` pipeline.
- Requires the run to create eligible posts, persisted insights, a healthy established state, and both positive and negative signals.
- Adds cleanup support that removes only the isolated test brand's performance rows and learning results.
- Adds a small Step 3A test panel on `/grow-brain?demo=1` with Run test and Clear test data actions.

## Safety
- Admin authentication is required server-side.
- Test rows never use a real brand_profile_id.
- The current brand dashboard is not contaminated by these test rows.
- Step 4 planning influence remains disabled.

## SQL
No new SQL is required. This version uses the Step 3A tables already created by `spreelo-v144.225-SQL.sql`.
