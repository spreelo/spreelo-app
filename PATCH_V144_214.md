# Spreelo v144.214 — Grow Brain step 2 completion: Threads performance

## Goal
Complete Grow Brain step 2 for every social channel currently supported by Spreelo publishing by adding Threads performance collection, while keeping the performance layer easy to extend for future channels.

## Added
- Threads is now a supported Grow Brain performance platform.
- Threads OAuth now requests `threads_manage_insights` together with the existing basic/publishing scopes.
- Per-post Threads insights are collected from the Threads insights endpoint.
- Normalized Threads metrics:
  - `views` → views
  - `likes` → likes
  - `replies` → comments
  - `shares` → shares when available; otherwise reposts + quotes as the propagation fallback
- Raw Threads provider data keeps replies, reposts, quotes and shares separately for later Grow Brain analysis.
- Existing Threads publish receipts already contain `thread_id`, so newly published and existing receipt-backed Threads posts can be discovered without changing the publishing flow.
- Performance provider dispatch is now centralized in `PERFORMANCE_PROVIDER_REGISTRY`, so future channels can be added as isolated collectors instead of changing the Grow Brain storage/scheduler architecture.

## Safety
- Existing Threads connections without `threads_manage_insights` continue to publish normally. Performance collection records a scope problem until the account is reconnected.
- Unsupported/unavailable Threads metrics remain NULL rather than being fabricated as zero.
- Metric requests use fallbacks so a temporarily unavailable Threads metric does not discard otherwise valid likes/replies/reposts/quotes data.
- Step 2 remains observational only: performance data still does not alter planning or generation.

## Future channels
Do not pre-build API collectors before a social connector exists. The shared database, scheduler, snapshots and normalized schema are already channel-agnostic. When LinkedIn or another provider is added, implement only its provider-specific collector + OAuth scope requirements and register it in the collector registry.
