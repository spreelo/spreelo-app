# Spreelo v144.188 — onboarding reference exact calibration

This release is a presentation-only refinement on top of v144.187.

## Changed
- Desktop onboarding modal widened to match the approved reference proportions and give the two-column recommendation cards enough room for complete copy.
- Removed desktop card text truncation/ellipsis.
- Mobile onboarding now uses the full available phone width instead of a narrow 390 px desktop-like cap.
- Added the right-side mobile chevrons from the approved reference.
- Rebalanced icon, copy, card, note and CTA sizing to mirror the approved desktop/mobile mockup.
- Replaced the oversized brand-logo overlay in the hero thumbnail with the neutral AI-studio visual treatment so a bad/missing brand logo cannot dominate the onboarding.
- Added fresh canonical-English v144.188 title/intro translation keys so non-English translation packs re-evaluate the title instead of keeping the old mixed-language value.

## Unchanged
- Smart onboarding recommendation logic.
- Plan activation/review behavior.
- Admin team/invite functionality.
- Credit logic, recurring plan logic and plan entitlements.
- Database schema.

## Database
No SQL migration is required for v144.188.
