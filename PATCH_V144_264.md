# Spreelo v144.264 — Social OAuth popup close reconciliation

## Problem
A social OAuth popup can close immediately after the external provider has completed authorization, while the parent Spreelo tab has not yet received the final `postMessage`. The parent page previously treated `popup.closed` as an immediate incomplete-flow state, which could show “Finish connecting your account” even when the connection had just succeeded.

## Fix
- Added a 5-second reconciliation window when an OAuth popup closes without a received result message.
- During the grace window Spreelo checks `social_connections` every 500 ms for a connected row for the current user, brand, and platform.
- If the connection appears, Spreelo treats the flow as successful, refreshes connections, and shows the normal success state.
- Only after the grace window expires without a connection does Spreelo show the existing “Continue connection” fallback.
- Reconciliation is cancelled if a real OAuth result message arrives or the user cancels/closes the flow.

## Scope
Client-side social channel OAuth coordination only. No SQL migration is required for v144.264.
