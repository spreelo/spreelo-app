# Spreelo v144.262 — Billing clarity + currency-safe loading

## Changes
- Added **Plan & billing** as a dedicated left-sidebar navigation item linking directly to `/settings?tab=billing`.
- The billing sidebar item is highlighted while the billing tab is open; Settings remains highlighted for the other settings tabs.
- The existing plan/credit card in the sidebar now also links directly to the billing tab.
- Increased spacing below the free-credit banner so it no longer touches the plan cards.
- Increased free-credit banner typography to 14 px title / 13.5 px supporting text for readability.
- Removed the visible provisional-currency flash: plan prices and credit-pack prices are withheld until `/api/billing/status` has resolved the display currency.
- Added a compact in-place loading spinner while the correct billing currency is being resolved.

## Safety
- No Stripe price catalog values, checkout routes, entitlement rules, subscription logic, free-trial rules or Shopify billing logic were changed.
- No SQL migration is required.
