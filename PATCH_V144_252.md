# Spreelo v144.252 — Capability-aware AI Content Studio plan cache

## What changes

- AI Content Studio's local recommended-plan cache now includes the brand's current verified product-mode and service-mode availability in the cache identity.
- A brand that changes from no verified products/services to verified product/service mode can no longer reuse a recommendation created before those formats were available.
- Existing planning intelligence is unchanged: goals, channel compatibility, recency, customer learning, Grow Brain performance learning, campaign context, format weights, dates and times continue to work as before.
- No product-format quota or forced percentage was added.
- No Shopify catalog, Product Engine, generation, publishing or database logic was changed.

## Why

The previous cache key used brand + goal + post count + selected channels. That meant an older recommendation could survive after a brand's product/service capability changed. The new capability signature invalidates only those stale recommendation-cache entries by naturally switching to a different key.
