# Spreelo v144.176 — Carousel Product-First Opening + No Pagination

Base: **v144.175**

## Purpose
Tighten the five-product carousel creative plan so the first slide is never treated like a generic intro card, and prevent rendered slide-number overlays such as `1/5` or `3/5` from appearing in carousel images.

## Changes

### 1. Slide 1 is now explicitly product-led
The Sol creative-plan contract now requires slide 1 to be specific to **Product 1**.
It may still be catchy, but it may **not** be a broad collection intro or a headline that could fit the entire carousel.

Examples of now-disallowed opening behavior:
- generic overview/opening lines like “Fem favoriter till grillen”
- theme-only hooks that do not clearly belong to Product 1

### 2. Safety fallback for generic first-slide headlines
If the creative-plan output still proposes a first-slide headline that does not anchor to the verified Product 1 title, Spreelo now falls back to the verified product title for slide 1 instead of keeping the generic heading.

This only affects the product-copy planning layer.
It does **not** change the verified product image / product-integrity flow.

### 3. No visual slide numbering
The creative-plan prompt and the GPT-Image slide-render prompt now both explicitly forbid:
- page numbers
- fractions
- sequence markers
- pagination/progress text

Examples blocked:
- `1/5`
- `2/5`
- `3/5`
- `5/5`

### 4. Metadata role cleanup
Ordinary product slides now use `product` role metadata, while only slide 5 keeps the `product_cta` semantic role.
The old first-slide `product_hook` role is removed for this flow so the data matches the new product-first behavior.

## Intentionally unchanged
- Exactly **5 slides**
- **1 product per slide**
- Slide 5 still shows **Product 5 + closing CTA**
- **No sixth AI outro slide**
- Existing product image generation / product integrity safeguards
- Existing carousel identity review
- Rescue retry gate behavior from v144.174
- Focused-carousel reuse fix from v144.175

## Database
No SQL or schema migration required.

## Regression intent
This version is intended to preserve the current good product-image quality while tightening only the carousel copy/layout contract:
- keep product rendering unchanged
- remove generic opening slide behavior
- remove slide-number overlays
