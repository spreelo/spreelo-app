# Spreelo v144.266 — Meta page-selection diagnostic hotfix

This hotfix fixes a regression introduced by the v144.265 diagnostic instrumentation.

## Fix

- Removes accidental references to POST-only diagnostic variables from `GET /api/meta/page-selection`.
- Keeps the v144.265 diagnostic logging for the POST/save flow.
- Ensures the POST diagnostics now record the authenticated user ID and selected brand ID correctly.
- No OAuth behavior, popup behavior, trial rules, credit-award rules, Stripe logic, or social-provider configuration is changed in this patch.

## Why

v144.265 could throw `ReferenceError: diagnosticUserId is not defined` / related diagnostic-variable errors while loading the Facebook page-selection screen. That caused `GET /api/meta/page-selection` to return HTTP 500 before the real Facebook page-selection flow could be tested.

## Test

1. Deploy v144.266. No SQL required.
2. Open Social channels and connect Facebook once.
3. Confirm the Facebook page list loads.
4. If the connection still fails after selecting a page, copy the Vercel lines beginning with `[meta-page-selection]` and `[social-trial]` plus the final error line.
