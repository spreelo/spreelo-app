# Spreelo v144.270 — Growth Agent V1

## What this adds
- A safe Growth Agent layer on top of the existing rolling content planner.
- Reads existing brand/profile data, recent successful content, customer learning, Grow Brain performance insights, active automation rules and upcoming calendar opportunities.
- Uses one integrated strategist (not multiple debating agents).
- Applies a soft 60/20/20 exploitation/exploration/strategic-content policy across time.
- Gives the planner a small, bounded nudge for proven performance and a small penalty for repeated formats.
- Carries Growth Agent reasoning and product-freshness guidance into the existing automation slot prompts.
- Does not replace or mutate Shopify import, rescue, website/product discovery, brand analysis or the existing content-generation engine.

## Safety / feature flag
Growth Agent V1 is OFF by default.

Enable globally in Vercel:
- `GROWTH_AGENT_V1=true`

Or enable only for selected test users:
- `GROWTH_AGENT_V1_USER_IDS=<supabase-user-id>[,<another-user-id>]`

If `GROWTH_AGENT_V1_USER_IDS` contains any IDs, that allow-list takes precedence over the global flag.

## Database
No SQL migration is required for v144.270. It only reads existing Spreelo data/tables already used by Grow Brain and the planner.

## Test
Run:
- `npm run test:v144.270`

The test checks the V1 decision layer, bounded adjustments, preservation policy, and propagation of Growth Agent guidance to the existing content planner.
