# v144.257 — Shopify App Pricing bridge

- Adds Shopify App Pricing as the billing provider for Shopify App Store installations.
- Keeps Stripe billing unchanged for direct Spreelo customers and manual Shopify connections.
- Uses Shopify Partner API `activeSubscription` as the authoritative subscription source.
- Discovers the installed Shopify app GID/handle through Admin API instead of trusting client input.
- Maps Shopify plan handles `starter`, `growth`, `pro` to Spreelo's existing plans and credit allowances.
- Synchronizes active plan, interval, period, pending plan change and cancellation state into `user_credit_balances`.
- Adds hourly billing reconciliation because Shopify App Pricing no longer sends subscription update webhooks after April 28, 2026.
- Preserves purchased credits when subscription credits refresh.
- Annual Shopify billing still refreshes Spreelo plan credits monthly.
- Prevents URL `plan_handle` tampering from granting entitlements; only Partner API data can grant a paid plan.
- Blocks Stripe/Shopify provider conflicts to prevent accidental double billing.
- Hides Stripe-only extra credit packs from Shopify App Store customers for now.
- No Product Engine, content generation, social publishing, Shopify catalog or ordinary customer generation logic was changed.
