# Spreelo v144.177 — Per-post Emojis/Hashtags + Carousel Caption Consistency

Base: **v144.176**

## Purpose
Make emoji and hashtag behavior consistent across Spreelo, expose the settings clearly per planned post, and align the Mass Test carousel naming with AI Studio without touching the working carousel image/product pipeline.

## Changes

### 1. Emojis + hashtags default ON
New planned posts continue to default to:
- `include_emojis = true`
- `include_hashtags = true`

Older rules where either value is null/missing are now also interpreted as ON by the automation generator and stored post record unless the value is explicitly `false`.

### 2. Visible per-post controls in the plan rows
Every planned format now shows two compact Spreelo-styled controls directly in the row:
- Emojis — On/Off
- Hashtags — On/Off

The controls apply to every content type, including product posts, carousel, FAQ, tips, guides, etc.

Behavior:
- before activation: changing a toggle updates the planned slot and is saved with the plan
- after activation / when editing an existing plan: changing a toggle updates the matching `automation_rules` row immediately
- newly activated rows are linked back to their created rule IDs so the same controls keep working without rebuilding the plan
- duplicated draft rows deliberately do not inherit the source rule ID

### 3. Responsive UI
Added dedicated responsive styles for the two controls:
- desktop: compact chips in the existing “Published to” section
- medium widths: wrapping without colliding with channel chips
- mobile: two equal-width controls
- very narrow mobile: controls stack vertically

Breakpoints are included for 900 px, 620 px and 390 px.

### 4. Carousel now respects the same caption preferences
The Sol five-product carousel creative-plan prompt now receives the actual per-rule emoji and hashtag preferences.

Hashtags:
- ON: Sol must return 3–6 relevant hashtags in a structured `hashtags` array
- Spreelo appends them at the end of the caption in a consistent format
- OFF: the schema requires an empty hashtags array and Spreelo strips any accidental hashtag text
- existing safe fallback captions keep their hashtags if Sol falls back

Emojis:
- ON: Sol is instructed to use a small number of natural relevant emojis when useful
- OFF: Sol is explicitly forbidden to use them and Spreelo also removes accidental pictographic emoji characters as a final safety layer

### 5. Mass Test carousel naming aligned with AI Studio
The canonical Mass Test label is now:

`AI-designed carousel – 5 products`

The Mass Test definition also describes the current five-slide contract:
- five verified products
- five coordinated AI-designed slides
- slide five also carries the closing CTA
- no separate sixth outro slide

The old “Website carousel” label and old six-slide description are no longer used in this flow.
