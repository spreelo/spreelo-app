# Spreelo v144.323 — AI Control Center, safe foundation

- Adds admin page `/admin/ai-control` for per-purpose model selection.
- Keeps every v144.322 model as the default; SQL uses `ON CONFLICT DO NOTHING` so deployment never overwrites an existing admin choice.
- Only verified models are eligible for each capability. Transparent typography requires `image_alpha`.
- OpenAI `/v1/models` is used for availability discovery, but discovery alone never grants compatibility.
- Kling is included as video provider; Shotstack is untouched.
- If the SQL/table is unavailable, the admin API reports a warning and existing v322 generation continues unchanged.

## Required SQL
Run `supabase/v144_323_ai_control_center.sql` once before using saved admin selections.

## Safety note
Saved selections are request-scoped and wired into the main automation engine, content planning, brand analysis, calendar image generation and Kling submissions. Unmigrated specialist paths keep their v322 defaults rather than guessing. If settings cannot be loaded, every resolver falls back to the exact v322 model.
