# Deploy v144.216 — Grow Brain premium redesign

## Database
No SQL is required for this release.

## Deploy
1. Deploy the full v144.216 zip normally.
2. No environment-variable changes are required.
3. Open **Grow Brain** on both desktop and mobile after deployment.

## Quick checks
- Hero shows the new Grow Brain visual and intelligence-status card.
- 7 / 30 / 90 day and channel filters still work.
- KPI values still reflect real database values.
- The performance chart renders either the new combined chart or the correct empty state.
- "What Spreelo is learning" uses translated user-facing labels where available.
- Channel cards retain publishing/measurement status correctly.
- Top content uses real post thumbnails when available and remains usable when no performance data exists.
- Mobile layout remains two-column for KPI cards and horizontally scrollable for top-content cards.

## TikTok
TikTok `video.list` remains opt-in as introduced in v144.215. This release does not change the TikTok review workflow.
