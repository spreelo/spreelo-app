# Spreelo v144.259 — polished local Extra Credits pricing

## Goal
Finalize the international-pricing package before first deployment. v144.258 already separated direct Stripe billing from Shopify App Pricing; v144.259 keeps that architecture and polishes the direct Extra Credits prices so the local amounts look intentional rather than mechanically converted.

## What changed
- Starter / Growth / Pro pricing is unchanged from v144.258.
- Shopify App Pricing is unchanged: $29 / $59 / $99 monthly and $290 / $590 / $990 yearly.
- Shopify Extra Credits remain unavailable, so Shopify customers are never sent to Stripe for an app-related add-on purchase.
- Direct Stripe Extra Credits now use clean local prices in all 29 fixed currencies.
- Every selected Extra Credits price stays within roughly 0–3% of the accepted SEK-relative FX reference used for v144.258.
- Examples:
  - NOK: 199 SEK exact ≈ 191.07 NOK → 189 NOK; 399 SEK ≈ 383.09 → 379; 699 SEK ≈ 671.13 → 669.
  - DKK: ≈ 131.77 / 264.19 / 462.84 → 129 / 259 / 459.
  - TRY: ≈ 983.50 / 1971.94 / 3454.60 → 999 / 1999 / 3499.
  - INR: ≈ 1925.85 / 3861.37 / 6764.66 → 1899 / 3899 / 6799.
- The runtime price catalogue remains the single source used by the direct billing UI and the Stripe currency-option sync.

## Complete review table
`STRIPE_LOCAL_PRICING_V144_259.csv` now includes all six customer-facing price items for every fixed currency:
- Starter
- Growth
- Pro
- +100 credits
- +250 credits
- +500 credits

For every row it shows:
- SEK reference price
- exact FX reference used for comparison
- selected fixed local price
- percentage difference
- annual 10-month price for subscription plans

## Stripe sync
The existing safe sync command is unchanged and reads the updated central catalogue:

```bash
npm run stripe:prices:preview
npm run stripe:prices:sync
```

The sync still:
- updates the existing Stripe Price objects by lookup key;
- preserves Price IDs and lookup keys;
- leaves SEK as the base currency;
- applies local `currency_options` independently;
- refuses live mode unless the explicit live safety flag is supplied.

## Database
No SQL or Supabase migration is required.

## Preserved behavior
- Direct Stripe subscriptions and lifecycle logic are unchanged.
- Adaptive Pricing remains the fallback where no fixed local currency option is available.
- Shopify billing remains fully separate from Stripe billing.
- Existing Shopify subscription/credit entitlement logic from v144.257 is unchanged.
