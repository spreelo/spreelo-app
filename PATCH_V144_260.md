# Spreelo v144.260 — Country-first global currency fallback

## Goal
Finish the international-pricing behaviour before deployment so billing currency is determined by the customer's market, never by the UI language.

## Direct Spreelo / Stripe
- Keeps the 29 fixed, rounded currencies and all plan/credit prices from v144.259 unchanged.
- Adds a static country/territory → primary ISO currency map covering 249 country/territory codes.
- Vercel/Cloudflare country headers remain the primary market signal.
- If the detected market currency has a fixed Spreelo price, that clean fixed price is shown in the app.
- If the detected market currency is not one of Spreelo's fixed currencies, the app shows the SEK base price and clearly explains that Stripe will show an available local price in Checkout.
- Stripe Adaptive Pricing remains enabled for this long-tail fallback.
- UI language no longer chooses billing currency. A locale helper is retained only for compatibility and may use an explicit region subtag; a language-only locale falls back safely.
- Existing paid customers keep their known fixed subscription currency when Spreelo has one, so an established subscription does not unexpectedly jump currency.

Examples:
- Denmark → DKK fixed Spreelo price.
- Italy → EUR fixed Spreelo price.
- Aruba → market currency AWG, no hand-rounded Spreelo AWG price, so Spreelo shows the SEK base price and Stripe handles available local presentation in Checkout.
- South Africa → market currency ZAR, same adaptive fallback behaviour.

## Shopify
- Unchanged from v144.259/v144.257.
- Shopify App Pricing remains USD: Starter $29, Growth $59, Pro $99 (annual $290/$590/$990).
- Stripe Adaptive Pricing and Stripe credit packs are not used for Shopify App Store billing.
