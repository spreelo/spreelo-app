# Spreelo v144.213 — Grow Brain step 2: performance collection

## Goal
Collect provider performance data without letting it change content strategy yet. This keeps Grow Brain step 2 observational and makes step 3 safe to build on real data.

## Added
- `post_performance_latest`: one normalized latest row per Spreelo post/platform.
- `post_performance_snapshots`: append-only history for later velocity/age-normalized learning.
- `post_performance_collection_state`: durable scheduling, retries, missing-scope/auth diagnostics.
- `/api/cron/collect-post-performance`: discovers published posts with provider receipts and collects due metrics every 15 minutes.
- Provider normalization for Facebook, Instagram, Pinterest, TikTok and YouTube.
- Facebook/Instagram publish receipts now persist native post/media ids for future analytics.
- TikTok OAuth requests `video.list` in addition to publishing scopes.
- Instagram OAuth requests `instagram_business_manage_insights` in addition to existing publishing/basic scopes.

## Normalized metrics
The common schema can hold:
- views
- reach
- impressions
- likes
- comments
- shares
- saves
- clicks
- engagements
- watch_time_seconds
- average_watch_time_seconds

A provider may leave unsupported/unavailable values null. Step 3 must compare metrics with platform/format awareness rather than treating null as zero.

## Collection behavior
- < 24h old: every ~3h
- < 7d old: every ~8h
- < 30d old: daily
- < 90d old: every ~3d
- older: weekly if a state remains active
- transient provider errors back off
- missing scopes/auth do not block publishing

## Safety
- Step 2 does **not** change planner weights or generation prompts.
- Existing posts without a reliable external provider id are not guessed/matched.
- TikTok connections created before v144.213 can continue publishing; analytics remains `scope_missing` until the account is reconnected with `video.list`.
- Instagram connections created before v144.213 may need reconnect before insight-only metrics are available.
