# Spreelo v144.256 — Shopify uninstall + compliance webhooks

## Purpose
Add the production webhook layer required before Shopify App Store review while keeping uninstall/privacy cleanup isolated from ordinary Spreelo account data.

## Endpoint
`POST /api/shopify/webhooks`

## Supported topics
- `app/uninstalled`
- `customers/data_request`
- `customers/redact`
- `shop/redact`

## Security
- Verifies `X-Shopify-Hmac-Sha256` against the raw request body with `SHOPIFY_CLIENT_SECRET` before trusting headers or JSON.
- Invalid HMAC returns HTTP 401.
- Uses `X-Shopify-Webhook-Id` for durable deduplication/retry safety.
- Persists only receipt metadata + payload SHA-256, never the raw compliance payload.
- Does not depend on the Shopify access token/session, which may already be revoked for uninstall/privacy delivery.

## Lifecycle behavior
### app/uninstalled
- Marks matching Shopify connection(s) `disconnected`.
- Blanks stored Shopify access/refresh tokens and scopes.
- Clears Shopify AI-store-data consent on the connection.
- Marks Shopify-derived product catalog rows inactive so they cannot continue feeding Product Engine after uninstall.
- Moves the Shopify Grow Brain web-data connection back to discovered/disconnected state.
- Does **not** delete the Spreelo user, brand, generated posts, plans or social accounts.

### customers/data_request + customers/redact
Spreelo currently requests only `read_products` and does not persist Shopify customer/order records, so these are acknowledged after HMAC verification and durable receipt logging. The handler deliberately fails closed if customer/order scopes are ever added in the future, forcing the privacy implementation to be extended rather than silently acknowledging an incomplete request.

### shop/redact
- Deletes the Shopify connection for the shop.
- Deletes pending Shopify onboarding handoffs for that shop.
- Deletes Shopify-derived Product Engine catalog rows/runs tied to the connected brand(s).
- Deletes Shopify provider web-data connection rows tied to the connected brand(s).
- For App Store-derived brands, strips exact Shopify website/product-source URLs when they still point to the redacted shop.
- Preserves the Spreelo account, brand shell, generated content and social connections because they are separate Spreelo customer data rather than Shopify access credentials.

## Database
Run `spreelo-v144.256-SQL.sql` before registering the webhooks. It creates the server-only `shopify_webhook_events` receipt table and idempotency RPCs.

## Shopify configuration
Use the snippet in `SHOPIFY_WEBHOOK_CONFIG_V144_256.toml.example` after linking Shopify CLI to the existing Spreelo app.
