# Spreelo v144.243 — Shopify Product Engine

## Goal
Use the connected Shopify Admin API as Product Engine's primary source for Shopify merchants, while preserving Spreelo's existing website/store discovery as a safe fallback.

## Changes
- Added `lib/shopifyProductCatalog.js`.
- Reads active Shopify products with `read_products` through the existing hardened per-brand OAuth/token-refresh flow.
- Product sync is bounded and paginated (max 120 products per Product Engine refresh).
- Only products that are ACTIVE, published to an Online Store URL, have a usable image, and have an available-for-sale variant become promotable candidates.
- Shopify product identity, image binding and current availability are treated as authoritative Admin API evidence.
- No product prices are imported into Product Engine.
- Shopify candidates are persisted in the existing `website_product_catalog` with `commerce_platform=shopify` and verification metadata.
- Stale Shopify API catalog rows are excluded from active selection; if fresh API verification is unavailable, normal website verification/discovery remains available.
- Whole-store single-product posts use Shopify catalog candidates before Store Map / public website discovery.
- Whole-store ordinary product carousels use Shopify catalog candidates before storefront discovery.
- Campaign carousels run product-level relevance review against Shopify products before public-web discovery; existing campaign safety/final-review logic remains authoritative.
- Customer-selected exact product/category/focus-page flows remain unchanged.
- Added Shopify API locked-product handling so Spreelo does not unnecessarily crawl/repair a product whose exact identity and image were already supplied by Shopify.

## Safety / compatibility
- No database migration is required.
- No new Shopify scopes are required beyond existing `read_products`.
- Non-Shopify brands use the pre-existing Product Engine paths unchanged.
- Shopify API failure/reconnect/throttling does not remove the existing public-website fallback.
