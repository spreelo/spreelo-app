# Spreelo v144.182 — Unified Smart Content Mix, Campaign & Weekly Strategy

Built on **v144.181 FINAL**.

## Purpose

This release updates the planning layer after the v144.181 editorial redesign so the same current content-format model is used consistently by:

- AI Content Studio
- Calendar Campaign Content Studio
- Weekly recurring plans with **Vary week to week** enabled
- recurring/upcoming-plan schedule previews

The existing generation contracts for the five established product formats are not changed in this release.

## One shared current format set

Automatically selectable strategic formats are now the five product formats plus the six current editorial formats:

### Product
- Product post (`website_item`)
- Product ad (`website_item_text_ad`)
- Animated product Reel (`animated_website_item`)
- AI product video (`ai_product_video`)
- Product carousel (`carousel_website_item`)

### Editorial
- Problem & solution (`problem_solution`)
- Tips & knowledge (`tips`)
- Question & answer (`faq`)
- Guide & decision help (`guide_choice`)
- Service in focus (`service_focus`) — only with verified service evidence
- Engagement & humour (`engagement_humor`)

Customer-directed builders such as Custom post, Giveaway and Post from webpage remain manual/customer-directed and are not silently selected by automatic strategy planning.

## Shared goal fit

`lib/contentPlanningStrategy.js` is the central strategy source for goal fit and type timing.

The three customer goals still produce genuinely different mixes:

- **Sell more** prioritizes demand, relevant products/services, product discovery, trust and conversion.
- **Get more followers** prioritizes engagement, useful/saveable content and discovery, with a smaller pure-sales share.
- **Build trust** prioritizes answers, useful knowledge, decision help, verified services and grounded problem solving.

AI product video is recognized by the planner as a premium motion format. It is available when strategically justified but receives a lower relative priority than equally effective lower-cost formats.

## Number of posts matters

The planner continues to use the requested 3 / 5 / 7 posts per week rather than treating every plan as the same fixed template.

Fallback planning now also keeps current formats unique for as long as enough safe formats exist and safely adapts product/service formats to the actual verified capabilities of the brand. Service-only and mixed product+service businesses therefore no longer rely on a product-centric fallback sequence.

## Shared day/time profiles

All current strategic types now have an explicit shared timing profile, including formats that previously fell back to generic times:

- Product ad
- Animated product Reel
- AI product video
- Guide & decision help
- Service in focus
- Engagement & humour

AI Content Studio, recurring-plan preview, upcoming-plan preview, saved-plan view and weekly execution use the same timing source instead of separate duplicated tables.

## Calendar Campaign Content Studio

Calendar campaigns now understand all current strategic formats, including **AI product video**.

Campaign selection still respects campaign phase and real dates first. Generic type timing may improve the time/day choice inside a compatible campaign phase, but it must not move an awareness, conversion, deadline or event-day post to a strategically wrong point in the campaign.

Product-driven campaigns remain guarded:

- Product formats require verified product capability.
- Service in focus requires verified service evidence.
- Product ad remains the required strong commercial format for verified product campaigns where the existing product-campaign policy applies.
- Product carousel remains limited.
- Animated Reel and AI product video are optional motion formats, not mandatory.
- AI product video is capped at one per campaign.
- Short campaigns normally use at most one motion product format across Animated Reel + AI product video.
- Motion is selected only when it materially improves the campaign idea.
- If an AI plan exceeds the allowed product-led share, premium motion is reduced before cheaper static product formats unless it still fits inside the valid strategic mix.

Season/date/holiday relevance is context only. It does **not** force Engagement & humour or any other post type.

## Weekly “Vary week to week”

Weekly adaptive selection keeps the existing 12-week history-balanced system and now also uses the same central goal-fit scores and product-type classification as AI Content Studio.

The recurring runner therefore considers:

- selected goal
- current safe rotation pool
- recent content-type history
- recent product-format share
- same-run repetition
- rotation position
- current goal fit
- current shared timing profile

The next week is not simply the same set in a different order when safe alternatives exist.

`Engagement & humour` remains static AI-image by default in automatic/adaptive plans, so the expensive 10-second AI-video variant is not silently selected. The manual media selector from v144.181 is unchanged.

## Backward compatibility

Historical retired editorial ids remain readable and mapped to the v144.181 current editorial types. Existing automation history and Rescue compatibility are preserved.

## i18n

No new customer-facing or Admin-facing copy is introduced by the v144.182 planning changes. Existing visible names/descriptions continue to use the v144.181 i18n keys. Internal strategy roles/prompts remain English implementation text.

English remains the canonical source language. `lib/i18n/defaultLabels.js` is unchanged from v144.181 FINAL.

## Database migration

The v144.182 planning changes themselves require no additional database schema.

Because v144.181 SQL has **not** been applied in the target environment, use the consolidated migration supplied with this release:

`supabase/v144_182_editorial_quality_smart_planning_CONSOLIDATED.sql`

It contains the full v144.181 database migration plus a v144.182 header. Run this file once **instead of** running the v144.181 SQL separately.

## Regression scope

Checks cover:

- all 5 current product + 6 current editorial formats in the shared strategy set
- explicit timing profiles for every current strategic format
- AI Content Studio current-format planning
- verified-service fallback gating
- AI product video campaign integration and cost-aware motion limits
- campaign phase/type-aware timing
- seasonality remaining context-only
- 12-week history-balanced weekly variation using shared goal weights
- automatic Engagement & humour remaining static-image by default
- unchanged established product-generation prompt contracts
- v144.181 editorial/credit controls
- v144.180 cardless-trial/analysis protection
- v144.179 429/Rescue cost protection
- persistent i18n integrity
- campaign Rescue and carousel regressions

Two much older regression scripts (`v144.57` and `v129`) contain assertions that already fail on the unmodified v144.181 FINAL baseline because those tests reference superseded UI/Campaign text. They are not regressions introduced by v144.182; the current v129.1 direct campaign policy test passes.
