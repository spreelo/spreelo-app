# Spreelo v144.231 — Grow Brain website-data connection UX foundation

## Customer experience
- Adds a one-time optional Grow Brain prompt when website data is not connected.
- `Not now` is persisted per brand in Supabase, with local fallback for demo mode.
- Adds a permanent website/business-data card in Grow Brain with separate Social, Website and Sales data states.
- Adds an always-available `Connect website` action.

## Smart discovery
- Adds authenticated server-side public-website inspection.
- Detects Shopify, WooCommerce, GA4, Google Tag Manager, WordPress, Wix, Squarespace and Webflow signals.
- Recommends the lowest-friction provider path.
- Public URL validation and redirect re-validation are used; Spreelo never requests FTP credentials or private website access.

## Important scope
- This version builds the persistent connection UX and discovery foundation.
- It deliberately does not pretend that Shopify/WooCommerce/GA OAuth is connected before those provider connectors are implemented.
- Selecting a path records `setup_pending`, not `connected`.
