# Spreelo v144.225 — Grow Brain step 3A: Performance Learning Engine

## What this adds
- A brand-specific performance learning engine on top of the normalized metrics from v144.213/v144.214.
- New persisted performance insights for content types and content formats, both globally and per channel.
- Same-channel normalization so Facebook reach is not compared naively with TikTok reach, etc.
- Conservative confidence that grows with repeated observations.
- Outlier protection so one viral or unusually weak post cannot dominate learning.
- Missing provider metrics remain missing and are never interpreted as zero performance.
- Posts younger than 12 hours are excluded from learning to reduce premature conclusions.
- A durable analysis state/queue and a 15-minute cron for incremental rebuilds.

## Safety boundary
This step is observational only. `brand_performance_insights` is NOT read by the planner or generation routes in v144.225. Automatic strategy changes belong to Grow Brain step 4.
