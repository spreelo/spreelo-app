# Spreelo v144.158 — Social Channels regression fix

## Fix

- Restored `app/social-channels/page.jsx` exactly to the working v144.156 implementation.
- Removes the v144.157 runtime regression where `ChannelCard` referenced `locale` outside its scope.
- Keeps the persistent i18n/database/source-fingerprint improvements from v144.157 everywhere else.
- No database migration is required for v144.158 beyond the v144.157 migration if it has not already been applied.

## Why

The v144.157 i18n patch changed token-expiry date formatting on Social Channels and introduced an out-of-scope `locale` reference inside `ChannelCard`. React therefore threw during page rendering before the social connection UI could load.

## Safety

The complete Social Channels page is restored byte-for-byte from v144.156 rather than modifying connect/disconnect/OAuth behavior. This isolates the correction from the platform integration logic.
