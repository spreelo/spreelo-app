# Spreelo v144.275 — Growth Agent V6: Commerce Learning

V6 adds a privacy- and attribution-gated commerce learning layer on top of V5.

## What changes

- Adds normalized `growth_agent_commerce_events` storage for explicitly sourced purchase, revenue, conversion, lead, add-to-cart and product-view events.
- Adds a durable `growth_agent_commerce_profiles` summary per brand.
- Growth Agent may softly favor a content format only after enough attributed commerce evidence exists.
- Social clicks/saves remain traffic proxies and are never silently treated as sales.
- Commerce influence is capped and cannot rewrite an already active calendar.
- Admin customer view shows commerce learning state, source, evidence count and attribution confidence.

## Important current limitation

This release intentionally does **not** add new Shopify order/customer scopes and does not persist Shopify orders. The existing Shopify compliance code explicitly avoids order/customer persistence. V6 is therefore safe to deploy before a future consented commerce connector: without normalized commerce events, commerce learning remains in `collecting` and has zero planning influence.

## Deployment later

Run after the V2–V5 Growth Agent migrations:

`supabase/v144_275_growth_agent_v6_commerce_learning.sql`

No new Vercel environment variables are required.
