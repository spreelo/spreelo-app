# Spreelo v144.178 — Vercel Build Hotfix for v144.177

Base: **v144.177**

## Purpose
Fix the production build syntax error introduced in `app/automation/page.jsx` while adding the v144.177 per-post emoji/hashtag controls.

Vercel error:
- `app/automation/page.jsx:9701`
- `Expected ',', got 'function'`

## Root cause
The `loadExistingAutomationRuleGroupIntoPlanner()` function accidentally contained a duplicated start of the `preparedSlots = groupedRules.map(...)` block. The first copy was left open and the second copy began inside it, so the parser reached the following function declaration while still expecting the previous expression to close.

## Fix
- Removed only the accidental duplicate block.
- Kept the intended v144.177 `automationRuleId` mapping on each restored slot.
- No behavior from v144.177 was removed.
