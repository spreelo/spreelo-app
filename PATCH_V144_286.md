# v144.286 — GPT-Image 2.5 Flare Kling typography

- Kling finished-video AI typography now calls `gpt-image-2.5-flare` directly.
- The request remains a single Images API edit with `background: "transparent"` and `output_format: "png"`.
- There is no first attempt with `gpt-image-2`, so a successful run does not pay for a failed GPT-Image-2 transparency request first.
- Overlay provider metadata now records `gpt-image-2.5-flare` so logs/admin diagnostics show the model that actually generated the artwork.
- Generation cost tracking recognizes GPT-Image 2.5 Flare separately at the current pinned rates: text input $5/M, cached text $1.25/M, image input $8/M, cached image $2/M, image output $30/M.
- Existing deterministic SVG fallback remains only as the final safety net if the direct Flare request itself fails or its output fails Spreelo's overlay validation.
- No SQL changes.
