# Spreelo v144.233 — Shopify App Store onboarding

## What changed

- App Store / Dev Dashboard launches now start Shopify OAuth immediately, before Spreelo UI is shown.
- Uses Shopify's verified staff identity to create/sign in to the matching Spreelo account without asking for another password.
- Runs a second offline OAuth pass and stores an expiring offline access token + rotating refresh token for background product access.
- New merchants can get a Spreelo brand workspace created automatically from the Shopify store.
- Existing merchants are matched to a brand automatically where the store/domain makes the match unambiguous.
- Existing multi-brand merchants get a simple brand picker only when a safe automatic match is not possible.
- The Shopify store URL is filled automatically; App Store customers never type a `.myshopify.com` address.
- Shopify App Store acquisition source is saved for later Shopify Billing / attribution decisions.
- Temporary onboarding credentials are stored in a server-only table and are wiped after the store is claimed.
- Explicit merchant consent is recorded before Shopify store data is used to personalize Grow Brain / AI content for the store.
- Shopify AI consent is isolated per brand and versioned; the UI explicitly states that Shopify data is not used to train a shared model across customers.
- Existing Grow Brain → Shopify connection flow now records the same explicit AI consent when the merchant chooses the Shopify connection.
- Fixed nested Shopify onboarding route imports so production bundling resolves the root Shopify helper correctly.

## Intentionally not included yet

- Shopify products are not yet wired as the primary source for the full Product Engine. The verified `/api/shopify/products` connector from v144.232 remains in place and is the next integration step.
- Order/customer scopes are still not requested. v144.233 remains `read_products` only.
- Shopify Billing is not enabled yet; acquisition source is stored so billing rules can be implemented before public paid App Store launch.
